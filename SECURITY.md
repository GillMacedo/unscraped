# Security

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/GillMacedo/unscraped/security/advisories/new), not in a public issue.

A case where `unscraped` disagrees with Prometheus Operator is a normal bug. Report it in a public issue unless it involves a security problem in unscraped itself. `unscraped` is a diagnostic aid and doesn't enforce anything.
